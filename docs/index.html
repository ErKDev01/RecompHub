Como começar

  1. Baixe e abra

    Coloque o RecompHub.exe numa pasta sua, como Documentos ou a área de trabalho. Não precisa instalar.

  2. Escolha a pasta dos jogos

    O hub sugere o disco com mais espaço. Se você já tem recomps, aponte para a pasta onde eles estão.

  3. Instale e coloque o seu jogo

    Escolha um recomp no Explorar. Ele usa os arquivos da sua cópia original, e o hub avisa o que falta.

Perguntas

Os jogos vêm junto?

Não. O Recomp Hub não distribui jogo nenhum. Cada recomp usa os arquivos da sua própria cópia (ROM, ISO ou dump), e o hub ajuda a colocá-los no lugar certo.

Apareceu "O Windows protegeu o computador". E agora?

Clique em Mais informações e depois em Executar assim mesmo. O aviso aparece porque o programa não tem assinatura digital paga, e não porque foi encontrado algum problema. Se quiser, confira o arquivo no VirusTotal antes de abrir.

É seguro instalar recomps pelo hub?

O hub só baixa pacotes do GitHub de cada projeto, por HTTPS, e confere cada arquivo com o hash publicado. Mesmo assim, instalar um recomp é rodar um programa feito por outra pessoa: o hub mostra as estrelas e a idade do projeto para você decidir.

Preciso de conta?

Não. O Recomp Hub roda só no seu PC e consulta apenas páginas públicas: o allrecomps, o GitHub e sites de imagens dos jogos. Ele não envia os seus dados para lugar nenhum.

Como desinstalo?

Apague o RecompHub.exe e as pastas RecompHub dentro de %APPDATA% e %LOCALAPPDATA%. Os seus jogos continuam na pasta de jogos.
